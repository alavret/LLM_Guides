# Назначение
Данный репозиторий содержит информацию о начале работы с агентским ПО.
На текущий момент предлагаются инструкции по установке первоначальной настройке Hermes Agent.

# Содержимое

Выполните по шагам:

[Настройка Model Hub](<Setup Model Hub.md>)  
Инструкция по получению доступа к моделям GPT Model Hub в облаке MWS CP: создание сервисной учётной записи, генерация API ключа, активация сервиса, добавление моделей (deployment) и получение URL для подключения ПО к моделям.

[Начальная настройка Hermes Agent](<Setup Hermes Agent.md>)  
Инструкция по установке Hermes Agent: получение загрузчика с официального сайта, загрузка компонентов (включая Python) и первоначальная настройка через `hermes setup` — подключение Custom endpoint (URL и API Key, например, для MWS Model Hub), выбор протокола, модели по умолчанию, размера контекстного окна, уровня размышлений, среды выполнения, плагинов, TTS и поиска.

[Интерфейс и возможности Hermes Agent](<Tune Hermes Agent Desktop.md>)  
Обзор настройки десктопного приложения: редактирование списка моделей, иерархия сущностей (Профиль → Проект → Сессия), базовые правила через файлы `SOUL.md` и `AGENTS.md`/`HERMES.md`, работа с профилями и проектами, Capabilities (навыки, tools, коннекторы), messaging-шлюзы, уровни разрешений на выполнение команд и многослойный механизм памяти.

[Навыки в Hermes Agent](skills.md)  
Что такое скиллы для LLM, как они устроены и для чего нужны; способы добавления новых скиллов (поиск, установка из GitHub, создание родными средствами агента); список библиотек навыков и описание скиллов из папки `skills/`.
